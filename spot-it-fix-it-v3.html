Read each issue below, then choose the POUR principle it violates. You'll see right away whether you're right, and what the fix looks like.

This is the page the four issues below come from.

Issue 1

The tagline above the Shop button reads "Stay dry in style with our lightweight, wind-tested umbrellas," rendered in light grey text on a white background.

Sample fix:Increase the contrast of the tagline and the Shop button so the text is easy to read against the background, using a dark color instead of light grey.
Issue 2

Each product's Add button is small, with very little space around it or between the three product cards.

Sample fix:Make each Add button larger with more padding around it, and add more space between the three product cards so they're easier to tap without hitting the wrong one.
Issue 3

The link in the top-right corner reads only "Click here," with no indication of where it leads.

Sample fix:Rewrite the top-right link with clear, complete text that describes where it goes, for example, View All Umbrellas, instead of Click here.
Issue 4

The Order section's name field has no visible label above it, just placeholder text reading "Your name" inside the box.

Sample fix:Add a permanent label above the name field that stays visible even after the user starts typing, rather than relying only on placeholder text.
