Easy to understand without reading the code. The name tells you exactly what it does, so AI, and any developer, can be confident about what calling this function will actually do.
const doSomething = () => {

Identical behavior, but the name gives away nothing. Reading "doSomething" tells you to expect anything. AI would have to guess at intent here the same way a human reader would, less confidence, more room for a mismatch between what's named and what's built.
Same code, same behavior, different names, and a real difference in how much either a person or AI can trust what they're looking at without digging further. That's abstraction working for you, or against you.
